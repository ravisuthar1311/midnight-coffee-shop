# ☕ Midnight Coffee — Coffee Shop Website

A modern coffee shop website designed to showcase delicious coffee, a welcoming atmosphere, and an elegant café experience. Built using HTML5, CSS3, and Bootstrap, this project focuses on clean design, attractive layouts, and responsive web development.

## 🌐 Live Demo

**[Visit Midnight Coffee](https://ravisuthar1311.github.io/midnight-coffee-shop/)**

## ✨ Features

- Modern coffee shop design
- Responsive page layout
- Coffee menu featuring espresso, cappuccino, latte, mocha, and cold coffee
- Dessert showcase
- Hero and About sections
- Navigation between website sections
- Custom CSS styling and Bootstrap layouts

## 🛠️ Technologies Used

- **HTML5** — website structure
- **CSS3** — styling and layout
- **Bootstrap** — responsive design utilities
- **Git and GitHub** — version control and source code hosting
- **GitHub Pages** — static website hosting

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## 🎯 Project Purpose

This project was created to practice frontend development, responsive layouts, CSS styling, Bootstrap, and multi-section website design.
